# Employee Management REST API

## Overview
A backend application for managing employee records using Python, Flask, and MySQL.

## Features
- Create employee records
- Retrieve all employees and individual employee details
- Update employee information
- Delete employee records
- Validate required fields
- Prevent duplicate email addresses
- Return appropriate HTTP status codes

## Technologies
- Python
- Flask
- MySQL
- Flask-SQLAlchemy
- Postman

## Setup
1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure database credentials in a local `.env` file.
5. Run `python app.py`.

## API Testing
Use Postman to test the employee CRUD endpoints.
